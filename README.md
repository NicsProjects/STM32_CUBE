# STM32_CUBE

Proiect realizat în STM32 CubeMX și STM32 CubeIDE pentru un senzor ultrasonic HC-SR04.

Aplicația generează impulsul de trigger, măsoară timpul de întoarcere al semnalului ECHO și afișează distanța în centimetri prin interfața UART. Este un exemplu clar pentru achiziția și prelucrarea datelor de la senzori în sistemele embedded.
